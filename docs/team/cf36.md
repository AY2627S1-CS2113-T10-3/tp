# Chang Feng - Project Portfolio Page

## Overview

BusyNotFree is a Java command-line application that helps freelancers manage clients, projects, dated tasks and events, with saving between sessions. My contributions make deletion safer and allow users to recover deleted projects and clients while preserving their contents, relationships and identifiers.

## Summary of Contributions

- **Code contributed:** [tP Code Dashboard](https://nus-cs2113-ay2627-s1.github.io/tp-dashboard/?search=CF36&breakdown=true).

- **Enhancements implemented:**
  - **Deletion with confirmation:** Implemented `project.delete`, `client.delete`, `client.delete_note`, `task.delete` and `event.delete`. Prompts identify the affected record; invalid answers preserve the pending operation, while cancellation and end of input leave data unchanged. Client deletion checks project links before prompting and again before removal, preventing broken relationships even for completed projects. Evidence: merged [PR #31](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/31) and [PR #89](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/89).
  - **Trashcan and project recovery:** Added `trashcan.list` and project restoration. Independent snapshots retain tasks, events, dates, project status and task completion. Restoration checks client availability and ID conflicts before registering a project, then removes its trash entry only on success. Extended existing persistence to retain snapshots across restarts, accept older files without trash data and prevent ID reuse. This required coordinating command state, model ownership and storage. Evidence: merged [PR #89](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/89).
  - **Client recovery:** Extended `trashcan.restore` to accept client IDs and restore original names and ordered notes. Conflicting or invalid requests preserve retained data. Restoring a client allows its projects to be restored separately; sorting clients during saving prevents reload failures after recovering older records. Evidence: merged [PR #96](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/96).
  - **Permanent cleanup:** Implemented `trashcan.empty` with confirmation, cancellation and end-of-input handling. Clearing removes all retained contents while preserving active records and ID counters; the existing save path persists the change. Evidence: merged [PR #96](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/96).
  - **Ordering, design and validation:** Fixed immediate numeric ordering after project/client restoration, including IDs beyond three digits ([project tests](https://github.com/AY2627S1-CS2113-T10-3/tp/blob/master/src/test/java/busynotfree/model/ProjectRestoreOrderingTest.java), [client tests](https://github.com/AY2627S1-CS2113-T10-3/tp/blob/master/src/test/java/busynotfree/model/ClientRestoreOrderingTest.java)). Separated snapshot storage from command handling and extracted shared [ID validation](https://github.com/AY2627S1-CS2113-T10-3/tp/blob/master/src/main/java/busynotfree/model/ProjectIdValidator.java). Added tests for invalid input, confirmation, snapshot isolation, failed restoration, persistence and unchanged counters ([PR #89](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/89), [PR #96](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/96)). Also implemented `help` ([PR #31](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/31)) and added internal assertions ([PR #38](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/38)).

- **Contributions to the User Guide:** Documented all five deletion commands and the [Trashcan section](../UserGuide.md#trashcan), including syntax, examples, confirmation, errors, recovery limits and persistence. Updated help, command summaries and numbered-note examples. Evidence: [PR #89](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/89), [PR #96](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/96).

Updated activation bars, restoration sorting, user stories and manual checks. Evidence: [PR #89](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/89), [PR #96](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/96), [diagram sources](https://github.com/AY2627S1-CS2113-T10-3/tp/tree/master/docs/diagrams).
