# Yap Ting - Project Portfolio Page

## Overview

BusyNotFree is a Java command-line application that helps freelancers manage
clients, projects, dated tasks and events. My contributions focus on project
tracking and helping users list, update and find projects by status and deadline.

## Summary of Contributions

- **Code contributed:** [tP Code Dashboard](https://nus-cs2113-ay2627-s1.github.io/tp-dashboard/?search=yt0812&breakdown=true).

- **Enhancements implemented:**
  - **Project listing:** Implemented `project.list` to display each project's
    ID, name, status and deadline in creation order.
  - **Project status management:** Implemented `project.status PROJECT_ID STATUS`
    to update a project's status while preserving its other details. Evidence:
    [PR #30](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/30) and
    [PR #40](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/40).
  - **Project status filtering:** Implemented `project.filter STATUS` to show
    projects with a selected status. It validates the status and accepts
    `active`, `paused`, `completed` or `cancelled` without changing project data.
  - **Deadline ordering:** Implemented `project.deadlines` to list projects
    from the earliest deadline to the latest, preserving creation order when
    deadlines are the same.
  - **Overdue project tracking:** Implemented `project.overdue` to show active
    projects whose deadlines have passed, excluding paused, completed and
    cancelled projects. Evidence:
    [PR #80](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/80).
  - **Startup UI:** Added an aligned pixel-style BusyNotFree startup banner and
    updated the related UI test output. Evidence:
    [PR #91](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/91) and
    [PR #95](https://github.com/AY2627S1-CS2113-T10-3/tp/pull/95).

- **Testing:** Added command-handler and project-manager tests covering project
  listing, status changes, valid and invalid input, status filtering, deadline
  ordering and overdue project detection.

- **Contributions to the User Guide:** Documented all five project-tracking
  commands—`project.list`, `project.status`, `project.filter`,
  `project.deadlines` and `project.overdue`—in the [User Guide](../UserGuide.md),
  including their formats, examples, validation and result behavior.

- **Contributions to the Developer Guide:** Added a dedicated project-tracking
  design section covering command routing, validation, model and UI
  responsibilities, design considerations and verification for all five
  project commands. Also updated the product scope, non-functional
  requirements, glossary and manual testing instructions. The manual test
  sequence covers the five commands and the Java 25 build and verification
  workflow.
